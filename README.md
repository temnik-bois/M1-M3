# M1-M3

Public release repository for M1 and M3.

M1 and M3 are reasoning machines for AI-and-memory substrates, developed by Egor Temnik as part of the BOIS / philomic systems project described in *God and the Auditor*.

## Contents

This repository is used to publish release archives for M1 and M3.
